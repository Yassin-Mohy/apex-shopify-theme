# APEX Shopify Theme

Official Shopify theme for APEX Wear.

## About

APEX is a performance-wear brand focused on clean design, athletic fit, and functional essentials for training and everyday use.

This repository contains the custom Shopify theme used for the APEX online store.

## Features

- Custom APEX header and footer
- Product collection and catalog pages
- Product pages with size guides
- Cart drawer with quantity controls
- Free shipping progress tracker
- Custom search results page
- About, Contact, Shipping, and Return Policy pages
- Responsive mobile design
- Shopify checkout integration
- Custom domain support

## Theme Structure

- `assets` – CSS, JavaScript, fonts, and theme assets
- `config` – Theme settings
- `layout` – Main Shopify layouts
- `locales` – Language files
- `sections` – Main theme sections
- `snippets` – Reusable Liquid components
- `templates` – Shopify page templates
